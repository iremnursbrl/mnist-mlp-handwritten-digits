# Teslim bilgileri

**Öğrenci:** İrem Nur Sabırlı  
**Proje:** MNIST veri seti ile MLP tabanlı el yazısı rakam tanıma

**Depo bağlantısı:** https://github.com/iremnursbrl/mnist-mlp-handwritten-digits

Kodlar, çalıştırma yönergeleri, 12 eğitim koşusunun sonuçları, eğitilmiş modeller, öğrenci el yazısı görselleri ve değerlendirme raporu depoda bulunmaktadır.

## İnceleme sırası

1. [README](../README.md): kurulum, eğitim ve tahmin komutları.
2. [Deney raporu](../results/main/RAPOR.md): yöntem, hiperparametreler, ölçümler ve yorumlar.
3. [El yazısı sonucu](../results/handwriting/handwriting_report.md): 11 rakamın tahmini.
4. [Sunuma hazırlık](SUNUMA_HAZIRLIK.md): model ve deney tasarımına ilişkin açıklamalar.

Ödev yönergesine göre teslim için depo bağlantısı paylaşılır. Bağlantı, dersin ödev teslim alanına öğrenci tarafından iletilmelidir. Deponun yayımlanması, ders platformunda teslim işleminin yapıldığı anlamına gelmez.
